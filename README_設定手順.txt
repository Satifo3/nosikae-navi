駅ナビ v1.4 アプリ内検索版

変更点
- 外部のYahoo!路線情報へ移動する処理を完全削除
- 検索結果は必ず駅ナビ内に表示
- 駅すぱあとアクセスキーを直接入力する簡単モードを追加
- Cloudflare Worker方式も引き続き選択可能
- 駅候補、乗換、時刻表、運行情報を同じ接続方式で取得

最短設定
1. 駅すぱあとAPIのアクセスキーを取得
2. GitHub Pagesで使う場合、駅すぱあと側の利用ドメインに自分のGitHub Pagesドメインを登録
3. 駅ナビ右上の⚙︎ → 接続方法「アクセスキーを直接入力」
4. キーを貼り付けて保存
5. 以後、検索ボタンを押すと駅ナビ内に結果表示

※アクセスキーをHTML本体に直書きしていません。localStorageに保存します。
※公開端末・第三者と共有する端末ではWorker方式を推奨します。
